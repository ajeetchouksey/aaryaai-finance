# Third-party components bundled in `aaryaai_finance/web`

| Component | Licence | Use |
|---|---|---|
| [Chart.js](https://www.chartjs.org/) | MIT | charts |
| [marked](https://marked.js.org/) | MIT | rendering assistant replies |
| [DOMPurify](https://github.com/cure53/DOMPurify) | Apache-2.0 / MPL-2.0 | sanitising rendered HTML |
| [Barlow, Barlow Condensed](https://fonts.google.com/specimen/Barlow) | SIL Open Font License 1.1 | UI font |
| [IBM Plex Mono](https://github.com/IBM/plex) | SIL Open Font License 1.1 | numbers |

They are vendored so the app works fully offline. The aaryaai name and logo in `web/brand/` belong to aaryaai; forks should replace them with their own.
