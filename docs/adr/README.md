# Architecture decision records

Short notes on structural decisions: data-model changes, new kinds of network access, security-model changes, new dependencies. One file per decision, named `NNNN-short-title.md`.

Each record has four parts:

1. **Context:** what made the decision necessary.
2. **Decision:** what we do.
3. **Consequences:** what gets easier, what gets harder, how to undo it.
4. **Status:** proposed, accepted, or replaced by another record.
